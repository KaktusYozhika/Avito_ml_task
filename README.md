# Avito ML Task

Решение задачи классификации автоматизированного трафика по истории событий cookie.

Цель - для каждого `cookie_id` оценить вероятность принадлежности трафика к автоматизированному классу.

**Основная метрика:** Precision при Recall ≥ 0.70.

---

## Результат

| Этап | Precision@Recall≥0.70 | PR-AUC | ROC-AUC |
|---|---:|---:|---:|
| Baseline: Random Forest, 2 признака | **0.1176** | 0.2602 | 0.6912 |
| Поздняя временная проверка | **0.8000** | 0.7885 | 0.9391 |
| Скрытая тестовая выборка | **0.83077** | - | - |

Финальная модель - ансамбль из трёх CatBoost с разными `random_seed`.

---

## Подход

В качестве baseline использовался `RandomForestClassifier` на небольшом наборе агрегированных признаков.

Основное решение построено на CatBoost и расширенном feature engineering.

Использовались признаки, описывающие:

- количество и типы действий;
- временные интервалы и регулярность активности;
- структуру сессий;
- поисковое поведение;
- разнообразие объявлений, категорий и локаций;
- платформу и User-Agent;
- характеристики движения курсора.

После расширения признакового пространства было получено 262 признака.

Затем признаки ранжировались по усреднённому feature importance CatBoost.  
Лучшее качество на втором периоде показал набор из 100 признаков, который и использовался в финальной модели.

## Валидация

Так как тестовая выборка расположена позже обучающей по времени, использовалось временное разделение данных вместо случайного train/validation split.

```text
06-12 апреля - обучение
13-16 апреля - проверка
17-19 апреля - поздняя временная проверка
20-26 апреля - скрытый тест
```

## Ограничения

Качество модели может меняться со временем, потому что поведение пользователей и автоматизированного трафика может отличаться на других временных периодах.

Модель учитывает временную и последовательную структуру поведения через специально построенные признаки. При этом подход основан на агрегировании истории событий, поэтому часть информации о точном порядке отдельных действий может теряться.

Также часть признаков, связанных с платформой, User-Agent и взаимодействием с интерфейсом, со временем может стать менее информативной, если изменятся приложения или способы автоматизации.

```text
scikit-learn 1.6.1
CatBoost 1.2.10
matplotlib 3.10.0
```

```bash
pip install -r requirements.txt
```

```text
bot_detection_challenge.zip
```
